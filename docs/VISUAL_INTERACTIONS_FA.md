# لایهٔ تعاملات بصری Void

این تغییر از الگوهای الهام‌گرفته از GSAP، React Bits و 21st.dev استفاده می‌کند، بدون آن‌که معماری فعلی FastAPI و HTML/CSS/JavaScript پروژه را به React تبدیل کند.

## موارد اضافه‌شده
- بازخورد hover بسیار ظریف برای اشاره‌گرهای دسکتاپ، با حفظ رنگ‌بندی مشکی/خاکستری Abyss.
- افکت ripple کم‌دامنه برای کلیک‌های ماوس، با حذف خودکار عنصر پس از پایان انیمیشن.
- حلقهٔ فوکوس قابل‌مشاهده برای صفحه‌کلید.
- GSAP به‌صورت اختیاری و lazy-load فقط روی دستگاه‌های دارای اشاره‌گر دقیق؛ اگر CDN در دسترس نباشد، رابط با CSS ادامه می‌دهد.
- احترام به `prefers-reduced-motion` و تنظیم `Save-Data`؛ لمس موبایل عمداً بدون ripple/حرکت اجباری می‌ماند.

## چرا همهٔ کتابخانه‌ها وارد نشده‌اند؟
- **Lenis:** فعلاً نصب نشده؛ پنل از قبل اسکرول طبیعی و چند ناحیهٔ اسکرول مستقل دارد. جایگزینی آن بدون آزمون گسترده ممکن است اسکرول منو/موبایل و دسترس‌پذیری را بدتر کند.
- **React Bits و 21st.dev:** کامپوننت‌های React را نمی‌توان مستقیم در HTML موجود قرار داد. از الگوهای تعامل آن‌ها استفاده شده، نه افزودن React و زنجیرهٔ build جدید.
- **Godly و Animos:** منابع الهام و ساخت دارایی‌اند، نه وابستگی runtime لازم برای پنل. از آن‌ها برای انتخاب جهت بصری استفاده می‌شود، نه افزودن اسکریپت سنگین.

## محدودیت آزمون
پیش‌نمایش GitHub Actions بررسی‌های تصویری خودکار را اجرا می‌کند؛ افکت GSAP به دسترسی مرورگر به CDN وابسته است، بنابراین fallback داخلی باید مستقل از CDN باقی بماند. این تغییر هیچ تنظیم Railway یا فرآیند دیپلوی زنده‌ای را تغییر نمی‌دهد.
