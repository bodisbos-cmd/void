# ماتریس امکانات Void — نسخهٔ یکپارچهٔ آزمایشی

## روش تست پس از انتشار
1. ورود به داشبورد و بررسی منوی همبرگری، صفحه‌ها و نقش‌ها.
2. ساخت یک سرویس آزمایشی با حجم/انقضای مشخص و بررسی محاسبهٔ مصرف.
3. بازکردن لینک اشتراک در مرورگر؛ سپس واردکردن همان لینک در v2rayNG/Hiddify/NekoBox.
4. تست جداگانهٔ هر پروفایل با اتصال تونل خاموش و سپس روشن؛ زمان پاسخ مسیر داخلی داشبورد را با پینگ برنامه یکی فرض نکن.
5. ساخت کلید API با scope محدود و آزمایش مجوزهای مجاز/غیرمجاز.
6. ساخت حساب viewer و اطمینان از ردشدن هر عملیات تغییردهنده.
7. دانلود بکاپ ZIP و فقط روی دادهٔ آزمایشی بررسی بازیابی.
8. اگر خطایی رخ داد، متن دقیق خطا، نام پروفایل، اپ، اپراتور و اینکه اتصال تونل روشن بوده یا نه را برای دور بعد ثبت کن.

هیچ تضمینی برای سازگاری تمام پروفایل‌ها با Railway Edge یا تمام اپراتورها وجود ندارد؛ نتیجه باید از اتصال واقعی به دست آید.
